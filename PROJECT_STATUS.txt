NYAYA AI - PROJECT STATUS REPORT
================================

Current Version: 1.1.0 (Production Ready + Enhanced UI)
Last Updated: April 27, 2026

Project Overview:
Nyaya AI is a state-of-the-art fairness analysis platform designed to detect, measure, and mitigate bias in AI systems. It provides a bridge between complex statistical fairness metrics and actionable human-centric insights, enabling developers and policy-makers to build more equitable AI.

## 🚀 UNIQUE SELLING PROPOSITION (USP)
--------------------------------------
1. **Human-Centric Explanations**: Converts complex statistical disparities into plain-English "Why" and "How" insights.
2. **Real-Time Mitigation**: Doesn't just detect bias; it actively provides reweighting and SMOTE-based mitigation strategies with before/after comparisons.
3. **Multilingual by Design**: Support for 10+ Indian languages, ensuring inclusivity across diverse regional contexts.
4. **Seamless Integration**: A "Drop-in" API and CSV upload flow that fits into any existing ML pipeline in minutes.
5. **Premium Aesthetic**: A glassmorphic, high-performance UI that makes data science accessible and visually stunning.

## 🛠 TECH STACK
-----------------
### Frontend
- **Framework**: Next.js 16.2.4 (App Router) + React 19
- **Styling**: Vanilla CSS + Tailwind CSS v4 (Design Tokens)
- **State**: Zustand (Atomic State Management)
- **Animations**: Framer Motion + Anime.js
- **3D**: Three.js + React Three Fiber (Fairness Score Visuals)
- **Icons**: Lucide React

### Backend & ML
- **Backend**: Node.js + Express (REST API Layer)
- **ML Engine**: Python 3.11 + Flask
- **ML Libraries**: Scikit-learn, Pandas, NumPy, Imbalanced-learn (SMOTE)
- **Database**: Firestore (NoSQL for Analysis History)
- **Auth**: Firebase Authentication (Google Sign-In + Email/Password)
- **Hosting**: Firebase Hosting

## ✨ CORE FEATURES
--------------------
### 1. Bias Detection & Analysis
- **Automatic Attribute Discovery**: Automatically identifies protected attributes (Gender, Age, Region, Caste).
- **Metric Suite**: Calculates Disparate Impact, Selection Rates, and Statistical Significance.
- **Intersectional Analysis**: Detects bias occurring at the intersection of multiple traits.

### 2. active Mitigation Pipeline
- **Sample Reweighting**: Automatically adjusts data weights to balance representation.
- **SMOTE Integration**: Synthetic oversampling for underrepresented minority groups.
- **Impact Comparison**: Side-by-side "Before vs After" visualization of fairness scores.

### 3. Interactive User Experience
- **Real-Time Analysis**: Instant feedback upon CSV upload or API call.
- **Fairness Score Ring**: Animated 0-100 score visualization using Three.js.
- **Multilingual Support**: Fully localized landing page and features in English, Hindi, Bengali, Tamil, Telugu, Marathi, Gujarati, Kannada, Malayalam, and Punjabi.
- **Theme Engine**: 4 Premium themes (Midnight, Nordic, Forest, Parchment).
- **Password Security**: Interactive show/hide toggles for secure credential management.

### 4. Reporting & Governance
- **PDF Export**: Audit-ready reports for compliance and leadership review.
- **Session History**: Persistent history of all past analyses stored in Firestore.
- **Data Privacy**: Built-in data governance controls and clear privacy framework.

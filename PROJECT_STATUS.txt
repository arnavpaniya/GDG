Current Version: 1.0.0 (Production Ready)

Project Overview:
Nyaya AI is a full-stack fairness analysis platform with integrated ML pipeline
for detecting and mitigating bias in AI datasets and machine learning models.

## HOW TO RUN

Terminal 1 - Backend:
```bash
cd backend && npm run dev
```

Terminal 2 - ML Service:
```bash
cd ml && python -m nyaya_ai.api_service
```

Terminal 3 - Frontend:
```bash
cd frontend && npm run dev
```

Then open: http://localhost:3000

## QUICK TEST

```bash
# Test backend
curl http://localhost:5000/api/v1/analyze/status

# Test ML service
curl http://localhost:5001/health

# Upload file
curl -X POST http://localhost:5000/api/v1/analyze/upload \
  -F "dataset=@backend/src/data/biased_dataset.csv"
```
